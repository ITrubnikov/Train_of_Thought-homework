# Модуль 18 — OpenClaw: always-on агент, который сам работает лесорубом

Домашка к Модулю 18 «OpenClaw — always-on на мессенджерах» — лекция на сайте курса.

Домашка из двух частей: сначала вы запускаете своего always-on агента (эта папка), потом даёте ему настоящее дело — он сам берёт из ратуши Cognopolis поручение «собрать N дерева» и выполняет его на живом жителе (отдельный репозиторий-заготовка). Ноутбука в модуле нет: всё в терминале, как в модулях 11 и 14.7. Артефакт — живой агент, который сам прочитал поручение и добрал склад до нормы.

## Часть A — поднять OpenClaw (эта папка)

### 1. Установка (~5 минут)

```bash
npm install -g openclaw@latest
openclaw --version
```

При обрыве сети (`ECONNRESET`) повторите. Команда выше ставит пакет через npm (менеджер пакетов Node.js — установщик программ для него); альтернатива npm — `curl -fsSL https://openclaw.ai/install.sh | bash`. Нужен Node.js 22.22.3+ (лучше 24.15+) — среда, в которой запускаются программы на JavaScript (OpenClaw — одна из них); скачивается с официального сайта [nodejs.org](https://nodejs.org); Windows — через WSL2 (способ запустить Linux внутри Windows; официальная инструкция Microsoft — [learn.microsoft.com/windows/wsl/install](https://learn.microsoft.com/windows/wsl/install)).

### 2. Онбординг (~10 минут)

```bash
openclaw onboard --install-daemon
```

Режим **QuickStart** (дефолты правильные: порт 18789, bind loopback, auth token — эти настройки уже безопасные, менять ничего не нужно). Провайдер — ваш: нагрузка у задачи лёгкая, так что основной смело ставьте дешёвую модель; годится и локальная — через Ollama (программа, запускающая модели прямо на вашем компьютере). Канал Telegram удобен, чтобы командовать агентом и видеть отчёты — бота создайте заранее у [@BotFather](https://t.me/BotFather) (`/newbot`); в ответ BotFather пришлёт токен — длинную строку-ключ, её вы вставите в мастер, когда тот спросит. Учтите: мастер токен **не проверяет** (опечатка всплывёт циклом `getMe returned 401` в логах). Мастер сам запустит Gateway — фоновую программу-дежурного: она держит связь с мессенджерами и живёт, пока живёт агент; проверка — `openclaw gateway status` → `Connectivity probe: ok`.

### 3. Pairing: впустите себя (~5 минут)

Напишите боту в Telegram — придёт 8-символьный код (живёт 1 час; одновременно ждать одобрения могут максимум 3 кода). На машине с Gateway:

```bash
openclaw pairing list telegram
openclaw pairing approve telegram <КОД> --notify
```

Первый одобренный становится владельцем команд бота. Следующее сообщение уже уйдёт в модель.

### 4. Минимум безопасности (~5 минут)

```bash
openclaw security audit
```

Gateway доступен только с этого же компьютера (слушает только loopback) — так и оставьте: **не пробрасывайте порт наружу**, то есть не открывайте к нему доступ из интернета (для тех, кто в теме: удалённый доступ — через Tailscale/VPN). Не выкладывайте файл `~/.openclaw/openclaw.json` в интернет (и не коммитьте его в git) и не публикуйте папку workspace (`~/.openclaw/workspace`) — рабочую папку, которую агент завёл при установке: в этом файле пароль бота (токен) лежит открытым текстом (плейнтекстом), а в папке — вся память агента (это git-репозиторий).

## Часть B — дать агенту дело: лесоруб на живом Cognopolis

Основное задание модуля — **always-on лесоруб**. Это прямое продолжение линии смолагентов-лесорубов курса (11.5 → 13.6 → 14.5 → 14 — именно в таком порядке модули идут в курсе, 14 стоит после 14.5, это не опечатка): тот же житель, тот же контракт `move`/`gather`/`get_map`/`get_character`, но мозг переехал из Gradio-чата в always-on демон OpenClaw — программу, которая постоянно работает в фоне. Агент сам просыпается по heartbeat, сам читает своё **поручение из ратуши** (Town Hall) новым инструментом `get_goal` и доводит склад до нормы. Ровно один кейс — «собрать N дерева».

Все заготовки — MCP-сервер лесоруба (тот же сервер из модуля 14.5, к которому добавлен один новый инструмент — `get_goal`), скилл-заготовка `cognopolis-woodcutter`, примеры конфига и heartbeat — лежат в отдельном репозитории:

**→ [github.com/ITrubnikov/Train_of_Thought-Cognopolis-18-homework](https://github.com/ITrubnikov/Train_of_Thought-Cognopolis-18-homework)**

Клонируйте его и следуйте README: подключить MCP-сервер к OpenClaw, поставить скилл лесоруба, дать жителю поручение в ратуше и включить пульс. Понадобится под-токен вашего жителя (экран «Жители» в игре) и Python 3.10+ для сервера.

## Критерии приёма (проверяете сами, преподаватель не нужен)

Часть A:

- [ ] `openclaw gateway status` показывает `ok`; бот отвечает вам в личке (pairing пройден).
- [ ] `security audit` без критики; порт не выставлен в интернет.

Часть B (детально — в README репозитория лесоруба):

- [ ] `openclaw mcp probe cognopolis` показывает подключённый сервер с инструментами, среди них `get_goal`.
- [ ] Агент сам прочитал поручение из ратуши (через `get_goal`), а не получил число текстом.
- [ ] После работы `get_character` показывает `stored.wood >= target`; «выполнено» заявлено только после этого подтверждения.
- [ ] На always-on прогоне виден тик с работой и тик с `HEARTBEAT_OK` (склад добран); тик — это одно пробуждение агента по heartbeat.

Артефакт для сдачи — лог/переписка, где виден вызов `get_goal`, набор дерева и финальное подтверждение по `stored.wood`, в чат курса как `[Модуль 18, ДЗ]`.

## Подводные камни (часть A)

- **Мастер не валидирует ключи.** Неверный Telegram-токен → цикл `getMe returned 401`. Чинится `openclaw config set channels.telegram.botToken "<токен>"`.
- **Gateway умирает вместе с терминалом** (закрыли окно — агент погас) — значит, фоновая служба (демон) не установилась. Простое лечение: держите команду `openclaw gateway` запущенной в отдельном окне терминала и не закрывайте его. Особые окружения лечатся по докам (для тех, кто в теме: причина — Docker/WSL1/нет systemd; варианты — отдельная сессия tmux или `docker compose`-путь).
- **Релизы почти каждую неделю.** Инструкция сверена с openclaw 2026.7.1-2 (июль 2026); если команда отвечает иначе — сверьтесь с [docs.openclaw.ai](https://docs.openclaw.ai/).

Грабли живого мира (кулдаун, авто-банк на доме, `get_goal: null`) — что это такое и как обходить, расскажет README репозитория лесоруба.
