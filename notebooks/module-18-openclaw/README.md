# Модуль 18 — OpenClaw: свой always-on агент в Telegram

Домашка к Модулю 18 «OpenClaw — always-on на мессенджерах» — лекция на сайте курса.

Здесь вы поднимаете агента, который живёт без вас: ставите OpenClaw на свою машину, подключаете Telegram-бота через BotFather и pairing, настраиваете cron-задачу «курс ETH/USD каждый час» с доставкой в личку и своими глазами видите экономику heartbeat — почему пустой чек-лист бесплатен, а «молчащий» агент с дефолтами жжёт токены. Ноутбука в этом модуле нет: вся практика — в терминале вашей машины, как в модулях 11 и 14.7. Артефакт — живой бот, который сам присылает вам курс раз в час.

## Что нужно до начала

- **Машина:** macOS или Linux; Windows — через WSL2. Установка занимает ~370 MB.
- **Node.js 22.22.3+ (лучше 24.15+):** проверьте `node --version`.
- **API-ключ LLM-провайдера** (Anthropic/OpenAI/др. — у вас есть с Модуля 6). Задача домашки тривиальная — смело ставьте дешёвую модель основной на время домашки; подойдёт и локальная через Ollama.
- **Telegram-бот:** создайте заранее у [@BotFather](https://t.me/BotFather) (`/newbot`) и сохраните токен. Важно: мастер OpenClaw токены **не проверяет** — опечатка всплывёт только циклом ошибок `getMe returned 401` в логах.
- Прочитанная лекция модуля 18: термины (Gateway, heartbeat, `HEARTBEAT_OK`, pairing, cron) здесь считаются знакомыми.

## Шаги

### 1. Установка (~5 минут)

```bash
npm install -g openclaw@latest
openclaw --version
```

Если `npm install` оборвался по сети (`ECONNRESET`) — просто повторите. Альтернатива npm — официальный скрипт: `curl -fsSL https://openclaw.ai/install.sh | bash`.

### 2. Онбординг (~10 минут)

```bash
openclaw onboard --install-daemon
```

Мастер задаёт вопросы; для домашки достаточно:

- Security-дисклеймер → прочитать и согласиться (мы выполним его советы в шаге 7).
- Режим → **QuickStart**. Дефолты правильные: порт 18789, bind loopback, auth token.
- Провайдер → ваш (дефолт в списке OpenAI; Anthropic — стрелкой ниже). Ключ вводится сразу.
- Канал → **Telegram**, вставьте токен от BotFather.
- Демон: на macOS поставится LaunchAgent, на Linux — systemd user unit (на VPS без залогиненной сессии понадобится `sudo loginctl enable-linger $(whoami)`); в Docker/WSL1 демона нет — Gateway запускается в форграунде и умрёт вместе с терминалом.

Мастер сам поднимет Gateway и покажет адрес Control UI. Проверка: `openclaw gateway status` — строка `Connectivity probe: ok`.

### 3. Pairing: впустите себя (~5 минут)

Напишите своему боту в Telegram что угодно. В ответ придёт «access not configured» с 8-символьным кодом (живёт 1 час, максимум 3 ожидающих кода). На машине с Gateway:

```bash
openclaw pairing list telegram
openclaw pairing approve telegram <КОД> --notify
```

Первый одобренный отправитель автоматически становится владельцем команд бота (`commands.ownerAllowFrom`). Следующее ваше сообщение уже уйдёт в модель — поздоровайтесь с агентом.

### 4. Узнайте свой chat_id и разрешите доставку

Cron будет писать вам **проактивно**, а pairing-одобрение покрывает только входящие. Узнайте свой числовой id — напишите боту и посмотрите поле `from.id`:

```bash
openclaw logs --follow
```

Личный chat_id — положительное число (отрицательные с `-100` — это группы). Добавьте его в allowlist доставки:

```bash
openclaw config set channels.telegram.allowFrom '["<ваш_id>"]'
```

### 5. Cron-задача «курс ETH/USD каждый час» (~10 минут)

Курс берём с keyless-эндпоинта CoinGecko — без единого ключа (у `web_fetch` OpenClaw ключи тоже не нужны; на `web_search` не завязывайтесь — он без ключа поискового провайдера молчит):

```bash
openclaw cron create "0 * * * *" \
  "Сходи web_fetch'ем на https://api.coingecko.com/api/v3/simple/price?ids=ethereum&vs_currencies=usd и пришли курс ETH/USD одной строкой." \
  --name "eth-hourly" --session isolated \
  --announce --channel telegram --to "<ваш_id>"
```

Не ждите часа — прогоните вручную и проверьте, что задача сохранилась правильно:

```bash
openclaw cron list --json   # поле delivery.to должно содержать ваш id
openclaw cron run <jobId> --wait   # прогон прямо сейчас; без --wait команда вернётся раньше доставки
```

Дальше задача сработает на ближайшей границе часа. Машина была выключена в это время? Не страшно: при старте Gateway пропущенные слоты схлопнутся в один догоняющий запуск (он придёт через пару минут после старта — не удивляйтесь «утреннему» курсу вечером).

### 6. Экономика heartbeat своими глазами (~10 минут)

Дефолтный онбординг создаёт непустой `HEARTBEAT.md` — а значит, каждые ~30 минут агент делает полный ход в main-сессии, даже когда «молчит» (лекция: порядка 100 тысяч токенов контекста на тик). Проверьте оба режима:

1. Опустошите чек-лист: `> ~/.openclaw/workspace/HEARTBEAT.md` — и подождите тик. В `openclaw logs --follow` появится пропуск с причиной `empty-heartbeat-file`: модель не вызывалась, тик бесплатный.
2. Скопируйте [`HEARTBEAT.example.md`](HEARTBEAT.example.md) в `~/.openclaw/workspace/HEARTBEAT.md` — на ближайшем тике агент отработает задачу (и промолчит `HEARTBEAT_OK`, если порог не превышен).
3. На время домашки дежурство не нужно — выключите пульс совсем: `openclaw config set agents.defaults.heartbeat.every "0m"`. Включите позже осознанно, с `isolatedSession`/`lightContext` и дешёвой моделью — рычаги из лекции.

### 7. Минимум безопасности (~5 минут)

```bash
openclaw security audit
```

Разберите вывод; `openclaw security audit --fix` подтянет безопасные дефолты. Сверьтесь с тремя правилами лекции: Gateway слушает только loopback (не пробрасывайте порт наружу — удалённый доступ только через Tailscale/VPN), `dmPolicy: pairing` на месте, песочница — тема Модуля 9.5. И два «не»: не коммитьте `~/.openclaw/openclaw.json` (телеграм-токен лежит там плейнтекстом) и не публикуйте workspace — это git-репозиторий с вашей памятью.

## Критерии приёма (проверяете сами, преподаватель не нужен)

- [ ] `openclaw gateway status` показывает `ok`; бот отвечает вам в личке (pairing пройден).
- [ ] `openclaw cron list --json` содержит задачу `eth-hourly` с вашим id в `delivery.to`.
- [ ] Пришло хотя бы одно **часовое** сообщение с курсом (не только ручной `cron run`).
- [ ] В логах виден пропуск heartbeat-тика на пустом файле (`empty-heartbeat-file`) — и вы можете объяснить, почему он бесплатный, а `HEARTBEAT_OK` — нет.
- [ ] Вы можете объяснить одним абзацем, почему задача про «каждый час» — cron, а не `interval: 1h` в HEARTBEAT.md.
- [ ] `security audit` без критических замечаний; порт не выставлен в интернет.

Артефакт для сдачи — скриншот переписки с ботом (видно часовое сообщение с курсом) плюс вывод `openclaw cron list --json`, в чат курса как `[Модуль 18, ДЗ] {скрин + вывод}`.

## Сколько это стоит

С выключенным heartbeat (шаг 6.3) постоянных расходов нет: единственный расход — один короткий агентный прогон в час в изолированной сессии (единицы тысяч токенов — копейки на любой модели). Если оставите heartbeat включённым с дефолтами — считайте сами: полный ход в main-сессии каждые полчаса, круглые сутки; именно поэтому лекция называет экономику тика главным рычагом always-on.

## Подводные камни

- **Мастер не валидирует ключи.** Неверный Telegram-токен → цикл рестартов канала с `getMe returned 401` в логах. Чинится: `openclaw config set channels.telegram.botToken "<токен>"` — Gateway подхватит без перезапуска.
- **Курс не приходит, хотя cron «delivered».** Первым делом `openclaw cron list --json`: проверьте `delivery.to` (ваш положительный id, не `@username`) и что id есть в `channels.telegram.allowFrom` (шаг 4).
- **Код pairing не приходит.** `/start` код не генерирует — напишите обычное сообщение; лимит 3 ожидающих кода, старые истекают за час.
- **Gateway умирает вместе с терминалом.** Значит, демон не установился (Docker/WSL1/нет systemd) — держите `openclaw gateway` в отдельной сессии (tmux) или используйте `docker compose`-путь из доков.
- **Релизы у OpenClaw почти каждую неделю.** Эта инструкция сверена с версией 2026.7.1-2 (июль 2026); если команда отвечает иначе — сверьтесь с [docs.openclaw.ai](https://docs.openclaw.ai/) и напишите в чат курса.
- **CoinGecko keyless** отдаёт ~10–30 запросов в минуту с IP и не предназначен для частого поллинга — для часовой учебной задачи это норм. Запасные keyless-источники: `api.coinbase.com/v2/prices/ETH-USD/spot`, Binance `ticker/price?symbol=ETHUSDT`.
