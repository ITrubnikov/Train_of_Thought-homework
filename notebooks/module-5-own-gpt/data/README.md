# Корпус Пушкина для модуля 5

Здесь должен лежать `pushkin.txt` — текстовый файл с произведениями
А.С. Пушкина. В сам репозиторий мы его не коммитим (5MB текста — лишний
вес), но даём три способа быстро получить.

Все произведения Пушкина (умер в 1837) — **public domain** во всём мире.

## Способ 1. Через HuggingFace datasets (самый быстрый)

```python
from datasets import load_dataset

ds = load_dataset("RussianNLP/russian_super_glue", split="train", streaming=False)
# ИЛИ любой публичный русскоязычный литературный корпус
```

Альтернативно — поискать через `huggingface_hub.list_datasets(filter="ru pushkin")`
актуальный датасет на момент прохождения.

## Способ 2. Прямое скачивание с public-domain источника

Несколько стабильных вариантов:

### Wikisource (рекомендуется)

```bash
# Например, "Капитанская дочка"
curl -L "https://ru.wikisource.org/wiki/Капитанская_дочка_(Пушкин)?action=raw" \
  -o data/pushkin_kd.wiki

# Очистка от вики-разметки делается отдельно (есть mwparserfromhell на pip)
```

### Project Gutenberg

В каталоге Project Gutenberg есть тексты Пушкина — поиск:
[`gutenberg.org/ebooks/search/?query=pushkin`](https://www.gutenberg.org/ebooks/search/?query=pushkin)

Скачивание плоского `.txt`:

```bash
# Пример: "Boris Godunov" в английском переводе
curl -L "https://www.gutenberg.org/cache/epub/30474/pg30474.txt" -o data/pushkin_eng.txt
```

Для модуля 5 (где мы хотим «псевдопушкин-русский» на выходе) английский
перевод не подойдёт — нужны русские оригиналы. Используй Wikisource или
способ 3.

### az.lib.ru (Lib.ru)

Старый стабильный архив русской литературы. Полное собрание Пушкина:
[`az.lib.ru/p/pushkin_a_s/`](http://az.lib.ru/p/pushkin_a_s/). Скачай
несколько `.txt` файлов и склей.

## Способ 3. Ручной copy-paste

Открой любую книгу Пушкина в Wikisource или az.lib.ru, выдели весь
текст, скопируй в `data/pushkin.txt`. На 5MB надо несколько крупных
произведений — например, «Евгений Онегин» + «Капитанская дочка» +
«Дубровский» + «Повести Белкина» вместе дадут около 1 МБ. Этого
достаточно для смок-теста; для нормальной демонстрации лучше
4-5 МБ.

## Минимальные требования к корпусу

- Кодировка: **UTF-8** (если скачал в Windows-1251 — конвертируй
  через `iconv -f windows-1251 -t utf-8 file.txt`).
- Размер: **минимум 500 КБ** для смок-теста, **5 МБ и больше** для
  внятного «псевдопушкина» на выходе.
- Никаких HTML-тегов, скриптов, навигации Wikisource — только текст
  произведений. Простая чистка через `bleach` или regex.

## Альтернатива: свой корпус

Не обязательно Пушкин — модуль 5 написан так, чтобы работать на любом
текстовом корпусе. Бери что хочешь:

- Любая публичная книга (Project Gutenberg, Wikisource).
- Свой блог, заметки, чат-логи.
- Тексты песен любимой группы (~1MB на полную дискографию).
- Markdown-репозитории.

Пайплайн модуля 5 будет работать на любом UTF-8 тексте. Просто
переименуй файл в `data/pushkin.txt` (или поправь путь в коде).
