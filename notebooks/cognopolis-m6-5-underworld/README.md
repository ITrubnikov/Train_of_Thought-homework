# Cognopolis · Урок M6.5 — Подземье: агент-рудокоп

Воркспейс и домашка к [Уроку M6.5: Подземье — агент-рудокоп](https://itrubnikov.github.io/Train_of_Thought/docs/game-lessons/m6-5-underworld/).

Наверху [Cognopolis](https://kindomklaster.com) добычу гейтит **время** (кулдаун), в Подземье — **код**: чтобы снять медь с жилы, агент решает Испытание — маленькую задачу класса GAIA над настоящими файлами (записка смотрителя + CSV-гроссбух). Промах бьёт по hp (бюджет — 5 промахов на серию), смерть сжигает вьюк целиком. «Шанс смерти» — частота ошибок вашего кода, а не кубик. Навигация при этом — те же 8 направлений, что в M1: «вообще по-другому» под землёй работает только добыча.

## Файлы в папке

| Файл | Зачем |
| --- | --- |
| [`workspace.ipynb`](workspace.ipynb) | **Воркспейс** — разбираем на занятии (или самостоятельно). «День шахтёра» end-to-end: дорога до входа (1,6) → `mine_descend` → навигация по горизонту 7×7 → испытание жилы (`mine_trial` + файлы) → решатель из трёх строк → `mine_attempt` → подъём с фиксацией (`mine_up` на entry) → зачисление на склад шахты (`mine_return`) → вынос в рюкзак у устья (`mine_depot_take`) → авто-банк дома. Всё собрано, `Run all` проходит целиком. |
| [`notebook.ipynb`](notebook.ipynb) | **Домашка** — соберите день шахтёра сами. Рабочий каркас `mining_day()` + решатель горизонта 1 (дан целиком — это легально) и три политики `# TODO`: маршрут, push-your-luck, робастность к отказам. `Run all` проходит и до, и после ваших правок. |

## Что нужно до начала

- **Токен живого мира.** Зарегистрируйтесь на [kindomklaster.com](https://kindomklaster.com) (логин + пароль) и скопируйте токен в Ратуше (вкладка «аккаунт»). **Демо-аккаунт `testuser` в шахту не пускает** демо-гард (`demo_forbidden`) — нужен свой аккаунт.
- Аккаунт Colab или Kaggle (или локальный Python 3.10+). GPU не нужен.
- **LLM-ключ НЕ нужен** — решатель первого горизонта детерминирован. **Золото не нужно** — дефолтная тачка (`barrow`) бесплатна.
- Сначала руками (кредо Подземья): дойдите жителем до тайла входа → «Спуститься в шахту» → пад навигации → на жиле панель «Копать»: решите одну печать сами. Блок «что понадобится агенту» в панели — мостик к этим ноутбукам.
- Желательно — пройденный M1 (навигация и петля агента оттуда) и лекция M6.5 до секции про решатель.

## Подводные камни

- **Смерть жжёт только вьюк** — рюкзак, склад и казна целы, житель у входа с hp 1. Но руда и стейджированный XP забега сгорают. Не тащите полный вьюк «ещё на одну жилу» при низком hp.
- **Жилы общие.** Заряды конечны и выбиваются другими шахтёрами; `vein_depleted` — честный отказ, реставрация придёт по таймеру (минуты). Идите к следующей жиле или подождите.
- **Горизонт двухжилен (D-097).** Среди жил горизонта 1 одна железная (`forge_ledgers`) — у неё другие файлы (`movements.csv`/`rates.csv`, без `ledger.csv`), и решатель урока её не берёт. Фильтруйте жилы по `class_key == "counting_seals"` (карта `mine_map` отдаёт класс по тайлу) и перепроверяйте `trial["class_key"]` перед подачей — иначе `solve()` упадёт на чужих файлах. Это и есть TODO-робастность.
- **Передавайте `series`.** `mine_attempt(answer, series=...)` с протухшей серией получит `series_changed` — отказ-объяснение ДО урона, не промах.
- **`mine_up` на entry — точка невозврата:** забег финализирован, дальше только `mine_return()` (зачисляет руду на склад шахты у устья, D-092) и `mine_depot_take()` (вынос руды в рюкзак на тайле входа). После финализации `mine_observe` отвечает `invalid_token` — это норма, итог читайте из результата `mine_return`.
- **Забег переживает обрыв ноутбука.** Повторный `Run all` продолжит начатый забег (`in_mine`), а не начнёт новый.
- **Два конверта.** Игровые мосты (`mine_descend`/`mine_return`) отвечают `{result, cooldown, character}`, сервисные `/mine/*` — `{result, cooldown, miner}`. `wait_cooldown()` работает с обоими.
- **mining — не про руду.** Поверхностная профа `mining` — «Каменотёс» (камень по кулдауну из M1); рудное дело `orecraft` — отдельная подземная профа, XP только за верную подачу и только при выходе живым.
- **Кулдаун — не баг.** В шахте действие идёт по базовому такту (~1 секунда), наверху добыча и бой — около десяти; `wait_cooldown()` держит ритм по числу из ответа сервера, спам не даёт преимущества.
- **Мир общий и учебный.** Ассерты в ноутбуках — пороги «не меньше», без «ровно»; если мир на паузе — подождите и перезапустите.
