# Модуль 4b — от MLP до nano-GPT

Заготовка к [Модулю 4b: От MLP до nano-GPT](https://itrubnikov.github.io/Train_of_Thought/docs/modules/04b-nano-gpt/).

Модуль **опциональный** — если твоя цель только агенты, можно идти прямо
в [Модуль 5](https://itrubnikov.github.io/Train_of_Thought/docs/modules/05-own-gpt/).
Но если не любишь, когда «80 строк PyTorch» остаются магией, — это
идеальный мостик. В [Модуле 4a](https://itrubnikov.github.io/Train_of_Thought/docs/modules/04a-micrograd/)
ты обучил **один нейрон руками**; здесь поднимаемся на пару ступенек:
один нейрон → слой → MLP → PyTorch → (опционально) CNN.

## Главная идея на пальцах

**Слой нейросети — это умножение матриц.** В 4a один нейрон считал
`tanh(w*x + b)` для чисел. Поставь рядом сотню нейронов на тех же входах
— получишь слой, и теперь `W` это табличка весов (матрица), а весь слой
считается одной строкой:

```text
h = tanh(X @ W1 + b1)   <- слой 1: умножение матриц + нелинейность
logits = h @ W2 + b2    <- слой 2: ещё одно умножение матриц
```

Backprop при этом — **тот же chain rule из 4a**, только локальные
производные стали матрицами, а не отдельными числами. А `loss.backward()`
в PyTorch — это ровно твой ручной backward, только быстрый и на GPU.
Отсюда и весь модуль: сначала пишем forward/backward руками на NumPy,
потом видим, что PyTorch делает то же самое в три строки.
