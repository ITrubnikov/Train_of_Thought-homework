# Модуль 4c — microgpt: весь GPT в 200 строк

Заготовка к [Модулю 4c: microgpt за 200 строк](https://itrubnikov.github.io/Train_of_Thought/docs/modules/04c-microgpt/).

Здесь ты **прочитаешь и покрутишь** один файл Карпатого `microgpt.py` — полный
GPT (обучение + attention + сэмплинг) на ~200 строках чистого Python. Ноль
зависимостей: никакого `pip install`, никакого PyTorch, всё на CPU. Файл сам
скачивается с гиста, сам докачивает датасет имён, сам обучается и в конце
печатает 20 новых имён.

Главная мысль, ради которой всё это: «настоящий» GPT — **не магия**, а
обозримый код, который читается за вечер. Недосягаем не он, а масштаб данных и
вычислений.

## Что нужно до начала

- Любой Python 3 — **никаких зависимостей** (только stdlib: `os`, `math`,
  `random`, `urllib`). Хватит Colab, Kaggle или `python3` в терминале.
- **GPU не нужен** и не ускорит: autograd скалярный (считает по одному числу),
  тензоров здесь нет. Так и задумано — цель файла читаемость, а не скорость.
- Один выход в сеть — разовая докачка датасета имён (`names.txt`, ~32 000 имён)
  при первом запуске.
- Из математики: достаточно идей из [модуля 4a](https://itrubnikov.github.io/Train_of_Thought/docs/modules/04a-micrograd/)
  (Value, forward, loss, backward, шаг). Матан не нужен.

## Главная идея на пальцах

Одна формула: **microgpt = micrograd из 4a + GPT поверх него**.

```text
  Value (autograd из 4a)
        │
        ▼
  кирпичики: linear, softmax, rmsnorm, attention
        │
        ▼
     gpt() ──► логиты ──► loss ──► backward() ──► Adam ──► правим веса
        ▲                                                      │
        └──────────────────────────────────────────────────────┘
```

Класс `Value` здесь — **тот же**, что ты писал руками в 4a, просто его много.
Из него собраны кирпичики слоёв, из них — функция `gpt()`. Она выдаёт логиты
(сырые предсказания следующей буквы), по ним считается `loss`, от него
`backward()` гонит градиенты назад, а `Adam` подкручивает веса. Тот же цикл
`forward -> loss -> backward -> шаг`, что в 4a.

Новое здесь только **attention** — механизм, которым модель решает, на какие
предыдущие буквы посмотреть, чтобы предсказать следующую. Он живёт внутри
`gpt()` (строки с `q`, `k`, `v` и `attn_weights = softmax(attn_logits)`).

Почему модель учится только на игрушке (списке имён), а не на Пушкине: scalar
autograd считает по одному числу за раз на CPU — для большого корпуса это
вечность. Чтобы выйти на настоящий текст, нужны тензоры и GPU. Это и есть
мостик к модулю 5: алгоритм тот же, меняется только железо.

## Что в ноутбуке

`notebook.ipynb` ведёт сверху вниз:

1. скачивает `microgpt.py` с гиста (stdlib, без `pip install`);
2. печатает файл с номерами строк и **карту** «где autograd, где attention, где
   сэмплинг» — чтобы ты мог показать пальцем;
3. запускает обучение (`!python microgpt.py`) — падающий loss и 20 новых имён;
4. домашка-твики: `temperature`, `num_steps`, свой датасет — каждый правит файл
   прямо из ноутбука маленькой утилитой `replace_in_file`.

Тяжёлая часть (обучение) помечена отдельно: пара минут на CPU.

## Домашка — «Прочитать и покрутить»

Задания совпадают с блоком в лекции:

1. покрути `temperature` (0.1 против 1.0) — как меняется «творческость» имён;
2. покрути `num_steps` (200 против 2000) — что с финальным loss и качеством;
3. замени датасет своим `input.txt` (список коротких слов, >= 500 штук) —
   модель начнёт «галлюцинировать» слова в твоём стиле;
4. покажи пальцем, где в файле класс `Value` из модуля 4a.

**Что сдать:** три сэмпла имён при `temperature` 0.1 / 1.0 + предложение про
разницу; 5 сгенерированных слов на своём `input.txt`; одно предложение, какая
строка соответствует `Value` из 4a.

**Критерий приёма:** можешь показать пальцем, где autograd, где attention
(внутри `gpt()`), где сэмплинг — и объяснить, почему код не потянет Пушкина.

## Как открыть

- **Colab:** открой через бейдж в лекции (он ведёт прямо на этот ноутбук) и
  прогоняй ячейки сверху вниз. Зависимостей нет.
- **Kaggle:** `+ Create -> New Notebook -> File -> Import Notebook`, вставь
  ссылку на этот `notebook.ipynb`. Input не нужен — файл качает датасет сам.
- **Локально:** `jupyter notebook notebook.ipynb`, либо просто скачай
  `microgpt.py` с гиста и запусти `python microgpt.py` в терминале.
