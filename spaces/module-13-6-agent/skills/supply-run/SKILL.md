# Supply run — пополнить склад деревом

Цель: в складе (`stored`) стало больше `wood`, житель снова дома на [0, 0], рюкзак пуст.

Главное правило навигации — **шагай реактивно, не считай весь маршрут заранее.**
Сделай ОДИН `move`, посмотри новый [x, y] в его ответе, реши следующий шаг по
нему. Так не нужно держать в голове длинный путь — только «куда шагнуть прямо
сейчас». Оси: `east` = x+1, `west` = x−1, `south` = y+1, **`north` = y−1**
(север УМЕНЬШАЕТ y — это легко перепутать).

## Шаги
1. `get_character` — узнай своё реальное [x, y] (мир персистентный, ты не обязательно дома).
2. `get_map` — выбери клетку с `tree`; если их несколько — ближайшую. Запомни её
   координаты как цель [tx, ty]. Клетки с врагами (goblin, wolf, ogre) целью не бери.
3. **Иди к дереву по одному шагу.** Каждый раз сравнивай своё текущее [x, y] с целью [tx, ty]:
   - если x > tx → `move west`; если x < tx → `move east`;
   - иначе, если y > ty → `move north`; если y < ty → `move south`;
   - если x = tx и y = ty — ты на дереве, переходи к шагу 4.
   После каждого `move` возьми новый [x, y] из ответа и повтори это сравнение.
4. Стоя РОВНО на дереве — `gather(resource="wood")`. Если пришло `no_resource_here`,
   ты не на клетке дерева: вернись к шагу 3. Нужно больше — повторяй `gather` до `inventory_full`.
5. **Иди домой на [0, 0] тем же реактивным способом:** `move west`, пока x > 0, затем
   `move north`, пока y > 0 (сверяя [x, y] после каждого шага). Дом сам разгрузит
   рюкзак — в ответе `move` появится `banked`.
6. `get_character` — проверь: в `stored` стало больше `wood`, рюкзак пуст, ты на [0, 0].

## Грабли
- Не считай длинный маршрут наперёд — решай КАЖДЫЙ шаг по свежему [x, y] из ответа `move`.
- `north` уменьшает y, `south` увеличивает — свежий взгляд на [x, y] спасает от путаницы.
- `gather` мимо клетки ресурса → `no_resource_here`: сначала встань РОВНО на дерево.
- `character_on_cooldown` — не ошибка, житель ещё занят прошлым делом (шаг ~1 с, добыча ~10 с;
  остаток — в `message`). Инструмент досиживает такт сам, так что код этот редкий: увидел —
  повтори тот же вызов.
- `at_map_edge` — шаг был наружу карты: возьми противоположную сторону.
- Следующий шаг ведёт на клетку врага? Обойди: шагни сперва по другой оси.
- Отдельного deposit нет: пока ты не на [0, 0], добыча лежит в рюкзаке и НЕ сдана.

## Пример (координаты условные — считай по своим)
Ты на [3, 4], дерево на [1, 2]. x 3 > 1 → `move west` (стало [2, 4]); снова x 2 > 1 →
`move west` ([1, 4]); теперь x = 1, смотрим y: 4 > 2 → `move north` ([1, 3]); ещё
y 3 > 2 → `move north` ([1, 2]); x = tx и y = ty → `gather(resource="wood")`. Домой:
x 1 > 0 → `move west` ([0, 2]); y 2 > 0 → `move north` дважды до [0, 0].

## Проверка
`get_character`: нужное дерево в `stored` (склад вырос), в `inventory` его нет, позиция [0, 0].
