# Supply run — пополнить склад деревом

Цель: дерево лежит на складе, житель дома, рюкзак пуст.

## Шаги
1. `get_character` — узнай своё реальное [x, y] (мир персистентный, ты не обязательно дома).
2. `get_map` — найди ближайший тайл `tree`; клетки с врагами (goblin, wolf, ogre) обходи.
3. `move` к тайлу по одной клетке (north / south / east / west), сверяя [x, y] в ответе.
4. Стоя ровно на тайле — `gather(resource="wood")`; нужно больше — повторяй до `inventory_full`.
5. Вернись домой на [0, 0] — дом разгружает рюкзак сам (в ответе move появится `banked`).
6. `get_character` — сверь склад (`stored`).

## Грабли
- `gather` мимо тайла ресурса → `no_resource_here`: сначала `move` РОВНО на тайл.
- `character_on_cooldown` — не ошибка, житель занят долю секунды: повтори тот же вызов.
- Отдельного deposit нет: пока ты не на [0, 0], добыча лежит в рюкзаке и НЕ сдана.
- Не заходи на клетки с врагами — это драка, а не заготовка дров.

## Проверка
`get_character`: нужное дерево в `stored` (склад вырос), в `inventory` его нет, позиция [0, 0].
