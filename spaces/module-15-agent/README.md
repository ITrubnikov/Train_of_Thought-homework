# Лесоруб на рельсах — LangGraph-агент с permission gate на живой игре Cognopolis (локальный запуск)

Готовый проект к Модулю 15 «LangGraph — оркестрация» (лекция на сайте курса):
тот же лесоруб, что вы собирали на smolagents в 11.5, гоняли через MCP в 14.5
и снабжали справочником в 14, — но петля агента впервые **нарисована явным
графом, и в неё врезаны ворота**. Перед рубкой (`gather`) процесс замирает
через `interrupt` и ждёт вашего «да»/«нет» прямо в чате — ровно как permission
gate в Claude Code из модуля 11, только собранный вашими руками. Инструменты
ходят на **реальный API игры** https://kindomklaster.com и ведут вашего
настоящего жителя по его под-токену.

Это пуант лекции живьём: **маршрут задаёте вы, модель работает на своих
участках маршрута**. Самое дорогое решение — рубить живое дерево в
персистентном мире — процесс не принимает сам: он останавливается и спрашивает
человека. Ответьте «нет» — и посмотрите, как модель переживает отказ; на живом
прогоне qwen2.5-7b, получив запрет, пошла к другому дереву — и ворота
остановили её снова. Правило живёт в процессе, а не в убеждениях модели.

Мозг агента — локальная модель из LM Studio через его OpenAI-совместимый
сервер http://localhost:1234/v1 (ключей не нужно вообще). Дропдаун
«Модель-мозг» показывает всё, что есть в LM Studio (● загружена, ○ подгрузится
на лету), «↻ Обновить» перечитывает список без перезапуска.

## LangGraph: что здесь нового против 11.5/14.5/14

- **Петля ReAct — явный граф.** `assistant` (модель с инструментами) +
  `tools` (готовый исполнитель `ToolNode`) + ребро `tools → assistant`,
  замыкающее цикл. То, что в smolagents пряталось за `agent.run()`, здесь
  нарисовано рёбрами — панель «Рельсы агента» показывает схему, выведенную
  прямо из кода (`draw_ascii`), без единого LLM-вызова.
- **Свой стрелочник вместо `tools_condition`.** Готовый стрелочник умеет два
  маршрута («в tools» / «в END»); наш добавляет третий — «в ворота», когда
  среди запрошенных вызовов есть инструмент из `GATE_TOOLS` (по умолчанию —
  `gather`). Это та самая «врезка в петлю» из лекции: счётчик бюджета, правило
  трёх неудач и ворота делаются одним и тем же приёмом.
- **Ворота = interrupt + checkpointer.** Узел `gate` зовёт `interrupt` —
  граф сохраняется и замирает, вопрос падает в чат. Ваше «да» продолжает
  нить через `Command(resume=True)` — вызовы едут в `tools` как ни в чём не
  бывало; «нет» — каждый tool_call закрывается честной ошибкой
  `denied_by_human` (протокол требует ответить на каждый вызов), и слово
  снова у модели. Без checkpointer это не работало бы вовсе: пауза — это
  сохранение, а не блокировка (подводный камень лекции).
- **Нить = память.** `thread_id` определяет диалог: по умолчанию каждый
  прогон — новая нить (истории прошлых задач топят слабую 7B), а
  `AGENT_MEMORY=1` держит одну нить до кнопки «Сбросить» — контекст между
  сообщениями хранит checkpointer, отдельного объекта памяти нет.
- **Контракт инструментов не изменился ни на строчку.** Те же
  move / gather / get_character / get_map, тот же конверт
  `{result, cooldown, character}` и ошибки `{code, message}` из 11.5 — только
  «паспорт» теперь собирает LangChain из сигнатуры и docstring
  (`Literal` → enum), см. пометки в `cognopolis_tools.py`.

## Два эксперимента на пять минут

**Выключите ворота.** Поставьте в `.env` строку `GATE_TOOLS=` (пусто),
перезапустите и дайте ту же задачу. Агент рубит без единого вопроса — граф,
модель и инструменты те же, исчез один узел на рельсах. Верните `gather` на
место и сравните ощущения: разница между «агент решает всё» и «дорогое решение
за человеком» — это одна врезка в петлю. Тот же паттерн вы собираете в
Задаче 6 ноутбука — только там ворота стоят перед `deposit` (в мок-лесу сдача
на склад — отдельный инструмент), а здесь перед `gather`: в живом мире, где
дом банкует сам, необратимое действие — сама рубка.

**Запретите рубку и следите.** На вопрос ворот ответьте «нет» — и читайте
трассу: вызовы закрыты `denied_by_human`, модель получает отказ, объясняется
или ищет обходной путь (наша 7B пошла к соседнему дереву — и снова упёрлась в
ворота). Склад при этом не меняется — проверьте панель персонажа: правда
живёт в state мира, а не в словах модели (факт-чек внизу чата покажет то же).

## Что нужно

- **Python 3.10+** и штатный `pip` (или `uv`).
- **LM Studio** с инструкт-моделью, умеющей tool use (в каталоге LM Studio
  такие помечены значком-молотком; проверено на `qwen2.5-7b-instruct-1m`).
  Модель без молотка ответит текстом — петля просто не закрутится.
- **Под-токен жителя Cognopolis**: интерфейс игры → Ратуша → вкладка
  «аккаунт» → «копировать». Токен остаётся в локальном процессе и уходит
  только на API игры.

## Как запустить

```bash
cd spaces/module-15-agent
python -m venv .venv && source .venv/bin/activate   # или: uv venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env-example .env                                # и впишите COGNOPOLIS_TOKEN
# LM Studio: вкладка Developer -> Start server (или `lms server start`)
python app.py                                        # откроется http://127.0.0.1:7860
```

Дальше в чате: «Добудь одно дерево (wood) и сдай его на склад» — и следите за
плашками. На `gather` процесс замрёт у ворот — ответьте «да» или «нет» тем же
полем ввода. В конце придёт факт-чек: дельта склада до/после — сдано на самом
деле или только заявлено.

## Частые вопросы

- **Агент «сделал» задачу, а склад пуст.** Смотрите факт-чек в чате: он
  считает дельту `stored` до/после — слабая модель любит объявить успех, не
  вернувшись на дом [0, 0] (только дом сдаёт рюкзак на склад). Попросите
  «вернись на [0, 0]».
- **Ворота не срабатывают.** Проверьте `.env`: `GATE_TOOLS=gather` (или не
  задан — это дефолт). Пустое значение выключает ворота.
- **«Процесс замер», а я написал новую задачу, не «да»/«нет».** Первое слово
  ответа читается как решение: всё, что не похоже на «да», считается отказом —
  безопасный дефолт для необратимых действий (как в permission gate).
- **GraphRecursionError.** Прогон упёрся в лимит шагов (80): модель ходила
  кругами. Прочитайте трассу — на чём зациклилась — и повторите или упростите
  задачу; это поучительнее зелёного прогона.
- **Хочу свой Cognopolis-сервер.** `COGNOPOLIS_BASE_URL=http://localhost:8000`
  в `.env` (токен — из Ратуши локальной игры).
