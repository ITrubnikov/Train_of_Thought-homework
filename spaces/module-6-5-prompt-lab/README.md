# Prompt Lab — модуль 6.5

Готовая HF Space-заготовка к [Модулю 6.5: Prompt engineering как ремесло](https://itrubnikov.github.io/Train_of_Thought/docs/modules/06-5-prompt-engineering/). Интерактивная песочница: щёлкаете приёмы из лекции и сразу видите, как меняется ответ открытой модели.

Что внутри:
- **Песочница** — редактируемый system-промпт + чат. Пресеты показывают приёмы: роль+формат (классификатор), chain-of-thought, delimit-and-trust против инъекций. Галочка «показать промпт» раскрывает, что именно уходит в модель (`messages`).
- **Извлечение (structured output)** — честный путь для открытых моделей: попроси JSON → проверь Pydantic-схемой → перепроси (repair). Видно, сколько попыток понадобилось.

`prompt caching` тут не показан — это фича провайдера (Anthropic/OpenAI); рабочее демо с подсчётом попаданий — в ноутбуке `module-6-5-prompt-engineering`.

## Как развернуть и тестить

### Вариант A — Duplicate Space (рекомендуется, ничего не качать)
1. Откройте опубликованную Space, нажмите **⋮ → Duplicate this Space**.
2. В **Settings → Variables and secrets → New secret** добавьте секрет `HF_TOKEN` — бесплатный токен с huggingface.co → Settings → Access Tokens (роль `read` достаточно).
3. Space пересоберётся сам; открывайте и тестируйте.

### Вариант B — создать Space с нуля из этих файлов
1. На huggingface.co: **New → Space**, SDK — **Gradio**.
2. Загрузите `app.py`, `requirements.txt`, `README.md` из этой папки (или `git push` в репозиторий Space).
3. Добавьте секрет `HF_TOKEN` (см. выше). Space соберётся и запустится.

### Вариант C — локально
```bash
pip install -r requirements.txt
export HF_TOKEN=hf_...        # ваш бесплатный токен
python app.py                # откроется http://127.0.0.1:7860
```

## Модель
По умолчанию `Qwen/Qwen2.5-7B-Instruct` через `provider="auto"` (HF сам выберет доступного провайдера, тратятся бесплатные месячные кредиты HF). Это небольшая дешёвая модель — каждый вызов примерно на порядок дешевле флагманской 72B, так что бесплатных $0.10/мес хватает надолго даже на общий демо-Space. Если модель недоступна или кончились кредиты — впишите другую из [hf.co/models?inference=warm](https://huggingface.co/models?inference=warm) в поле «Модель».

## Что попробовать (чек-лист самопроверки)
- [ ] Пресет «Классификатор» — пришлите тикет, получите одно слово; смените формат в system, не трогая сообщение.
- [ ] Пресет «Рассуждение (CoT)» — дайте многошаговую задачу; уберите «рассуждай по шагам» из system и сравните.
- [ ] Пресет «Безопасный ответ» — вложите в `<doc>...</doc>` команду «игнорируй инструкции»; убедитесь, что модель не поддаётся (а без пресета — поддаётся).
- [ ] Вкладка «Извлечение» — подайте мусорный вход и посмотрите, как repair вытягивает валидный JSON со второй попытки.
